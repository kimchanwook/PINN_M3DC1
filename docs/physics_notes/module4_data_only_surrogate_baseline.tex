\section*{Preface: why the baseline changed from a coordinate network to a full-field operator}

Module~1 fixed the reduced resistive-MHD physics. Module~2 built and verified a numerical solver that produces complete two-dimensional trajectories. Module~3 now exposes those trajectories as lossless full-field operator examples. The natural data-only learning problem has therefore changed.

The earlier Module~4 formulation asked a coordinate network to learn
\[
(x,y,t,\eta,\nu,A_0)\mapsto(\psi,U).
\]
That formulation represents a field by querying one point at a time. The revised formulation instead supplies the complete initial magnetic-flux and stream-function arrays and requests the complete target arrays at a chosen time:
\[
\left(\psi_0,U_0,\eta,\nu,t\right)\mapsto(\psi_t,U_t).
\]
This is an \emph{operator-learning} problem because the input and output contain functions represented numerically over the spatial domain, not merely a few scalar coordinates.

The revision is scientifically useful for two reasons. First, simulation codes naturally produce fields. A full-field surrogate therefore resembles the way a later high-fidelity simulation export would actually be consumed. Second, supplying the complete initial condition permits future datasets to vary the \emph{shape} of the initial plasma state, rather than describing every state through a small collection of hand-selected scalar amplitudes.

The revision does \emph{not} change the physical model, the reference solver, or the scientific claim boundary. The training arrays are still synthetic outputs of the project's two-dimensional reduced-MHD solver. They are not genuine M3D-C1 arrays. Likewise, the full-field tensors are numerical scalar arrays, not pictures.

\begin{warningbox}[\,: numerical fields are not images]
The neural operator consumes the stored scalar values of $\psi_0$, $U_0$, $\psi_t$, and $U_t$ on the declared grid. Contour plots, magnetic-field-line renderings, velocity arrows, PNG files, screenshots, color maps, and rasterized figures are presentation products and may not replace the numerical arrays in training.
\end{warningbox}

\begin{warningbox}[\,: Module 4 remains data-only]
A neural operator is not automatically physics-informed. Module~4 uses only labeled input-target field pairs to update its weights. Reduced-MHD equations may be evaluated after training as diagnostics, but if a PDE residual or other physical constraint contributes to the training objective, the experiment belongs to Module~5.
\end{warningbox}

\begin{warningbox}[\,: claim boundary]
Completing Module~4 demonstrates a data-only full-field surrogate of the project's synthetic two-field reduced resistive-MHD solution family. It does not demonstrate fidelity to genuine M3D-C1 output, realistic fusion geometry, extended-MHD closures, or arbitrary plasma initial conditions.
\end{warningbox}

\section{Scientific role of Module 4}
\label{sec:role}

\subsection{Four computational objects}
Several project components produce field values, but their meanings differ.

\begin{longtable}{p{0.20\textwidth}p{0.34\textwidth}p{0.36\textwidth}}
\toprule
Object & What it does & What determines its output \\
\midrule
\endfirsthead
\toprule
Object & What it does & What determines its output \\
\midrule
\endhead
Reduced-MHD reference solver & Numerically integrates the frozen two-field equations from one initial condition. & PDEs, initial fields, parameters, grid, time step, dealiasing, integrator, and numerical conventions. \\
Canonical trajectory dataset & Stores accepted numerical arrays and provenance. & Verified Module~2 runs and the Module~3 schema. \\
Module~4 neural operator & Learns complete target fields from complete initial fields and scalar context using labeled data only. & Operator architecture, labeled field pairs, transforms, loss, sampling, optimizer, and training choices. \\

\subsection{The controlled scientific question}
Let $\mathcal{G}_{\rm data}$ denote the trained data-only operator and $\mathcal{G}_{\rm phys}$ the later physics-informed operator. The central question is not merely whether $\mathcal{G}_{\rm phys}$ is accurate. It is
\begin{quote}
At the same labeled full-field data budget and on the same untouched physical cases, what changes when reduced-MHD information is added to a competent full-field operator baseline?
\end{quote}
Measured outcomes can include field error, derivative error, current-sheet fidelity, reconnection timing, data efficiency, parameter generalization, initial-state generalization, runtime, memory, and optimization reliability.

A negative result is scientifically valid. A physics-informed operator may optimize less reliably, may be sensitive to residual scaling, or may add little when dense field observations already determine the solution family.

\subsection{What ``baseline'' means}
\begin{definitionbox}
A \textbf{baseline} is a fully specified comparison method that answers the same prediction question under controlled conditions. A baseline should be competent rather than intentionally weak. Otherwise improvement can be attributed to avoidable defects in the comparator instead of the new method.
\end{definitionbox}

For the present periodic structured-grid problem, a competent baseline should use the correct tensor contract, training-only normalization, whole-case splits, adequate spectral resolution in the network, stable optimization, and complete-field evaluation.

\subsection{Why the full-field baseline is scientifically different from the old coordinate baseline}
A coordinate network learns field values through pointwise queries. A full-field operator instead learns a map between discretized functions. The change affects what constitutes one example, how batches are formed, what architectural inductive bias is useful, what generalization means, and how inference cost is measured.

It does \emph{not} change the underlying target trajectory. For every accepted case $c$ and time $t_n$, both formulations attempt to approximate the same numerical fields $\psi^{(c)}(x,y,t_n)$ and $U^{(c)}(x,y,t_n)$.

\section{From trajectories to supervised operator learning}
\label{sec:supervised}

\subsection{Supervised learning with field-valued inputs and outputs}
In ordinary supervised learning an example is an input paired with a desired output. Here both contain arrays. Let
\[
X_{c,n}=\left(\psi_0^{(c)},U_0^{(c)},\eta_c,\nu_c,t_n\right),
\qquad
Y_{c,n}=\left(\psi_n^{(c)},U_n^{(c)}\right).
\]
A neural operator with trainable parameters $\theta$ predicts
\[
\widehat Y_{c,n}=\mathcal{G}_\theta(X_{c,n}).
\]
Training changes $\theta$ to reduce disagreement between complete predicted and target fields.

\subsection{One trajectory produces many pairs but not many independent cases}
Suppose one accepted case contains $N_t$ saved times. The same initial state may be paired with several target times,
\[
(\psi_0,U_0,\eta,\nu,t_1)\mapsto(\psi_1,U_1),\quad \ldots,\quad
(\psi_0,U_0,\eta,\nu,t_{N_t})\mapsto(\psi_{N_t},U_{N_t}).
\]
These are distinct supervised examples but share the same physical trajectory. If 27 trajectories each contribute 100 target times, the dataset contains 2700 target-time pairs but only 27 independent physical cases.

\begin{warningbox}[\,: pair-count inflation]
Do not describe thousands of target-time pairs as thousands of independent simulations. Temporal snapshots from one trajectory are correlated and inherit the same initial condition and transport parameters.
\end{warningbox}

\subsection{The $t=0$ pair}
At $t=0$ the exact operator target is the input state itself:
\[
\mathcal{S}_{0}(\psi_0,U_0,\eta,\nu)=(\psi_0,U_0).
\]
This identity pair is useful as an acceptance test for tensor packing, transforms, channel order, and operator behavior. It should not dominate the training distribution merely because it is easy.

\subsection{Approximation, interpolation, extrapolation, and generalization}
The word \emph{generalization} is incomplete unless the held-out dimension is stated. Relevant tests include:
\begin{itemize}
  \item \textbf{transport-parameter interpolation}: unseen $(\eta,\nu)$ inside a declared training support;
  \item \textbf{transport-parameter extrapolation}: $(\eta,\nu)$ outside that support;
  \item \textbf{time interpolation}: target times inside the represented training interval;
  \item \textbf{time extrapolation}: $t>T_{\rm train}$;
  \item \textbf{initial-state interpolation/generalization}: unseen initial fields from a family represented during training;
  \item \textbf{out-of-family initial states}: new functional shapes not represented in training; and
  \item \textbf{resolution transfer}: evaluation on a different spatial grid.
\end{itemize}
These tests answer different scientific questions and must not be averaged into one unnamed ``generalization'' score.

\section{The exact Module 4 operator map}
\label{sec:operator_map}

\subsection{Primary map}
For case $c$ and target time $t$,
\begin{equation}
\boxed{
\mathcal{G}_\theta:
\left(\psi_0^{(c)}(x,y),U_0^{(c)}(x,y),\eta_c,\nu_c,t\right)
\longmapsto
\left(\widehat\psi^{(c)}(x,y,t),\widehat U^{(c)}(x,y,t)\right).
}
\label{eq:operator_map}
\end{equation}
All physical quantities are dimensionless under Module~1 normalization before optional neural preprocessing.

The operator is \textbf{time-conditioned}: it predicts a requested state directly from the initial state and target time. It is not required to predict intermediate snapshots sequentially.

\subsection{Why $A_0$ is not duplicated as a primary input}
The version-1 initial stream function is
\[
U_0(x,y)=A_0(\cos x-\cos y).
\]
Therefore the entire $U_0$ array already contains the perturbation amplitude. Supplying both $U_0$ and $A_0$ would duplicate the same information for the current family. Module~3 retains $A_0$ as metadata and for consistency checks, but the primary operator context is
\[
(\eta,\nu,t),
\]
not $(\eta,\nu,A_0,t)$.

\begin{warningbox}[\,: current initial-condition family is narrow]
Replacing the scalar $A_0$ by the complete $U_0$ field does not magically create initial-condition diversity. Version~1 still uses the fixed shape $\cos x-\cos y$ multiplied by different amplitudes. A strong claim of operator generalization to arbitrary plasma states requires additional independently verified initial-field families.
\end{warningbox}

\subsection{Why $J$ and $\omega$ remain derived outputs}
The primary target remains $(\psi,U)$. Current and vorticity are derived by
\[
J=-\Lap\psi,\qquad \omega=\Lap U.
\]
Predicting $J$ and $\omega$ as independent target channels would answer a different learning question and can permit inconsistent fields. They are valuable evaluation diagnostics because they test whether the operator reproduces spatial curvature.

\subsection{Coordinate network, time-stepper, and neural operator}
\begin{longtable}{p{0.21\textwidth}p{0.33\textwidth}p{0.36\textwidth}}
\toprule
Formulation & Typical map & Interpretation \\
\midrule
\endfirsthead
\toprule
Formulation & Typical map & Interpretation \\
\midrule
\endhead
Coordinate network & $(x,y,t,\mu)\mapsto q$ & Returns one field value at a requested coordinate. \\
Autoregressive time-stepper & $q(t_n)\mapsto q(t_{n+1})$ & Advances a state repeatedly; errors can accumulate recursively. \\

Module~4 uses the third formulation.

\subsection{What the operator is approximating}
For the frozen reduced-MHD initial-value problem there is conceptually a solution operator
\[
\mathcal{S}_t:(\psi_0,U_0,\eta,\nu)\mapsto(\psi_t,U_t).
\]
The data-only model seeks
\[
\mathcal{G}_\theta\approx\mathcal{S}_t
\]
over the declared domain of initial fields, transport coefficients, and times. Because the targets come from a finite numerical solver, the more precise statement is that $\mathcal{G}_\theta$ approximates the \emph{accepted discrete reference solution operator} represented by Module~2 and Module~3.

\section{Full-field tensors and scientific data semantics}
\label{sec:tensors}

\subsection{Canonical arrays versus learning tensors}
The canonical HDF5 trajectory is the authoritative scientific object. The learning tensor is a reversible view. For a common $N_x\times N_y$ grid, Module~3 defines
\[
\mat X\in\mathbb{R}^{B\times N_x\times N_y\times C_{\rm in}},\qquad
\mat Y\in\mathbb{R}^{B\times N_x\times N_y\times 2},
\]
for batch size $B$, before any framework-specific channel-first permutation.

\subsection{Version-1 input channels}
The frozen primary baseline broadcasts scalar context as constant spatial channels. The channel-last input is
\begin{align}
X[:,:,0]&=\widetilde\psi_0(x,y),\\
X[:,:,1]&=\widetilde U_0(x,y),\\
X[:,:,2]&=\widetilde\eta,\\
X[:,:,3]&=\widetilde\nu,\\
X[:,:,4]&=\widetilde t.
\end{align}
Thus $C_{\rm in}=5$. The last three arrays are constant over $(x,y)$ for one operator example.

Broadcasting does not claim that $\eta$, $\nu$, or $t$ are spatially varying. It is simply an architectural representation that places scalar context in the same tensor consumed by the lifting layer.

\subsection{Target channels}
The output channels are
\[
Y[:,:,0]=\widetilde\psi_t(x,y),\qquad
Y[:,:,1]=\widetilde U_t(x,y).
\]
Inverse transforms recover physical nondimensional fields before scientific evaluation.

\subsection{Logical axis order versus framework order}
A logical tensor may be stored as $[B,N_x,N_y,C]$ and then permuted to $[B,C,N_x,N_y]$ for a deep-learning framework. These are memory-layout choices, not changes in physics. Every permutation must be explicit and reversible.

\subsection{Why random crops are not part of the primary baseline}
Computer-vision pipelines often crop images. That would alter the physical periodic domain and discard global topology. The version-1 operator uses the full $2\pi\times2\pi$ field. Patch-based or domain-decomposed operators are separate experiments requiring boundary and overlap definitions.

\subsection{Common-grid requirement}
The primary FNO batch assumes a common periodic grid. One accepted production realization per physical case contributes to the learning release with identical $N_x,N_y,L_x,L_y$ and coordinate arrays. Verification runs at other resolutions remain linked provenance rather than silently resampled training cases.

\section{What a neural operator means}
\label{sec:operator_concept}

\subsection{From finite-dimensional vectors to functions}
A standard network maps vectors to vectors,
\[
\mathbb{R}^{d_{\rm in}}\to\mathbb{R}^{d_{\rm out}}.
\]
An operator conceptually maps functions to functions,
\[
\mathcal{G}:\mathcal{A}\to\mathcal{U},
\]
where $\mathcal{A}$ and $\mathcal{U}$ are function spaces. In computation, functions are represented by samples on a grid, so the implemented model still manipulates finite tensors. The term \emph{operator} describes the intended mathematical object and the architecture's treatment of spatially distributed input, not an escape from discretization.

\subsection{Discretization dependence and discretization awareness}
A neural operator is often designed so that its learned kernel can be evaluated on more than one resolution. That does not guarantee accurate zero-shot resolution transfer. Training data, Fourier truncation, normalization, grid spacing, and unresolved physical scales still matter. Version~1 therefore validates on the same accepted grid first.

\subsection{Local versus global receptive field}
A local convolution combines information from nearby grid points. Many layers are needed for distant regions to communicate. Spectral convolution transforms the field into Fourier modes and can couple information globally in one layer because each Fourier coefficient depends on the full spatial domain.

That property is attractive for MHD, where large-scale magnetic topology and localized current sheets interact. It is not a proof that spectral learning will resolve every thin structure.

\subsection{Why Fourier structure is natural for this project}
The synthetic solver already uses a doubly periodic Fourier pseudo-spectral representation. The domain is periodic and rectangular, with no physical wall. A Fourier neural operator therefore aligns naturally with the topology of the learning grid. This is an architectural convenience and inductive bias, not an additional reduced-MHD equation.

\section{The Fourier neural operator from first principles}
\label{sec:fno}

\subsection{Version-1 architecture choice}
The primary data-only neural operator is a two-dimensional Fourier neural operator (FNO) inspired by the operator-learning formulation of Li and collaborators \cite{Li2021}. The architecture has four conceptual stages:
\begin{enumerate}
  \item \textbf{lifting}: map the five physical/input channels to a wider latent channel space;
  \item \textbf{spectral blocks}: repeatedly combine global Fourier convolution with local channel mixing;
  \item \textbf{nonlinearity}: apply a pointwise activation after each block; and
  \item \textbf{projection}: map latent channels to the two target fields.
\end{enumerate}

\subsection{Lifting}
At each grid point define the five-component input vector
\[
\vect a(x,y)=
[\widetilde\psi_0,\widetilde U_0,\widetilde\eta,\widetilde\nu,\widetilde t]^T.
\]
A learned pointwise affine map lifts it to width $d$:
\[
\vect v_0(x,y)=P\vect a(x,y)+\vect b_P,
\qquad P\in\mathbb{R}^{d\times5}.
\]
The lifting operation does not mix different spatial locations. It creates a richer local feature vector before global spectral mixing.

\subsection{One spectral layer}
For layer $\ell$, let $\vect v_\ell(x,y)\in\mathbb{R}^{d}$. A simplified FNO block is
\begin{equation}
\vect v_{\ell+1}(x,y)
=
\sigma\!\left(
W_\ell\vect v_\ell(x,y)
+
\IFFT\!\left(R_\ell\cdot\FFT[\vect v_\ell]\right)(x,y)
+\vect b_\ell
\right).
\label{eq:fno_layer}
\end{equation}
Here:
\begin{itemize}
  \item $W_\ell$ is a learned pointwise channel-mixing matrix;
  \item $\FFT$ and $\IFFT$ are the two-dimensional discrete Fourier transform and inverse transform;
  \item $R_\ell$ contains learned complex weights acting on selected Fourier modes;
  \item $\sigma$ is a nonlinear activation; and
  \item the dot indicates multiplication across input/output latent channels for each retained wave number.
\end{itemize}

\subsection{Spectral convolution in component form}
Let $\widehat v_{\ell,c}(k_x,k_y)$ be Fourier coefficient $(k_x,k_y)$ of latent channel $c$. For an output channel $r$,
\[
\widehat z_{\ell,r}(k_x,k_y)
=
\sum_{c=1}^{d}
R_{\ell,rc}(k_x,k_y)\widehat v_{\ell,c}(k_x,k_y)
\]
for retained modes. Unretained modes of the learned spectral branch are set to zero. The inverse FFT returns $z_{\ell,r}(x,y)$.

Each learned $R_{\ell,rc}(k)$ is complex because Fourier modes carry phase. Implementations with real-valued input commonly use a real FFT representation and parameterize the independent half-spectrum.

\subsection{Why there is also a local $W_\ell$ branch}
Keeping only a finite number of learned Fourier modes would discard high-frequency content inside the spectral branch. The local pointwise branch $W_\ell v_\ell$ provides an additional path for information and channel transformation. The nonlinear combination of local and spectral branches is more expressive than either alone.

\subsection{Mode truncation}
Let the retained learned spectral band contain $M_x$ modes in $x$ and $M_y$ modes in $y$ under the implementation's FFT ordering. The choice controls a tradeoff:
\begin{itemize}
  \item too few modes can smooth thin current sheets and miss high-wavenumber structure;
  \item more modes increase parameter count and memory; and
  \item modes near the numerical cutoff may carry discretization noise rather than trustworthy physics.
\end{itemize}
The mode count is therefore a validation-selected hyperparameter and must remain within the resolved spectral content of the accepted reference data.

\subsection{Periodic domain and padding}
Many FNO examples pad nonperiodic domains to reduce wrap-around artifacts. The present version-1 domain is physically periodic, so the primary baseline uses \textbf{no nonperiodic padding}. Adding arbitrary zero padding would change the represented topology and must be treated as an architecture ablation rather than a default preprocessing trick.

\subsection{Activation function}
The data-only FNO does not require fourth-order automatic spatial derivatives, so several smooth activations are technically possible. For continuity with Module~5 and stable high-order diagnostic behavior, version~1 uses the Gaussian error linear unit (GELU) or another explicitly frozen smooth activation selected before the final test. If Module~5 requires differentiability with respect to scalar time through the network, the chosen activation must support that derivative reliably.

For the primary matched comparison, Module~4 and Module~5 use the same activation.

\subsection{Projection}
After $L$ spectral blocks, a pointwise projection maps latent features to two outputs,
\[
\vect q(x,y)=Q_2\,\sigma(Q_1\vect v_L+\vect b_1)+\vect b_2,
\qquad
\vect q=[\widehat{\widetilde\psi},\widehat{\widetilde U}]^T.
\]
The inverse field transforms then recover $(\widehat\psi,\widehat U)$.

\subsection{A frozen starting architecture}
A defensible initial configuration is:
\begin{itemize}
  \item grid: the common accepted Module~3 learning grid;
  \item input channels: $5$;
  \item latent width: $d=32$;
  \item spectral blocks: $L=4$;
  \item retained modes: $M_x=M_y=16$ as a starting point, validated against current-sheet fidelity;
  \item activation: GELU;
  \item output channels: $2$; and
  \item no nonperiodic padding.
\end{itemize}
These numbers are not physical constants. The exact trainable-parameter count must be logged automatically by the implementation.

\begin{warningbox}[\,: FNO is a baseline choice, not the definition of operator learning]
DeepONet, graph neural operators, convolutional encoder-decoders, U-Nets, and other function-to-function architectures can also represent operator maps. Version~1 freezes an FNO because the current data live on a common periodic Cartesian grid. A future unstructured M3D-C1 mesh may motivate a different operator architecture.
\end{warningbox}

\section{Scalar conditioning: time, resistivity, and viscosity}
\label{sec:conditioning}

\subsection{Why scalar context is broadcast}
The same $\eta$, $\nu$, and target $t$ apply to every spatial point in one example. Broadcasting them creates constant channels that are available to every lifted spatial location. The lifting and later nonlinear blocks can then learn interactions such as ``the same initial current sheet evolves differently when $\eta$ changes.''

\subsection{Time-conditioned operator versus recurrent integration}
The map
\[
(\psi_0,U_0,\eta,\nu,t)\mapsto(\psi_t,U_t)
\]
predicts the requested time directly. To obtain $t=3$, the network need not first predict $t=1$ and $t=2$. This avoids recursive error accumulation, but it does not guarantee extrapolation beyond the times represented in training.

\subsection{Continuous scalar input does not guarantee continuous physical accuracy}
Because $t$, $\eta$, and $\nu$ are numerical inputs, the network can be evaluated between sampled scalar values. The resulting prediction is only an interpolation candidate. Accuracy must be checked against independent accepted solver output.

\subsection{Potential alternative conditioning schemes}
Alternatives include a separate scalar multilayer perceptron whose embedding modulates spectral blocks, feature-wise affine modulation, or concatenation after lifting. These may improve parameter conditioning but introduce additional architectural choices. Broadcasting is retained as the transparent primary baseline.

\section{Physical nondimensionalization and neural preprocessing}
\label{sec:preprocess}

\subsection{Two transformations with different meanings}
Module~1 nondimensionalizes the physical PDE. Module~4 may then transform already dimensionless values for optimization. These operations must remain separate.

\begin{longtable}{p{0.26\textwidth}p{0.33\textwidth}p{0.31\textwidth}}
\toprule
Transformation & Purpose & Scientific consequence \\
\midrule
\endfirsthead
\toprule
Transformation & Purpose & Scientific consequence \\
\midrule
\endhead
Physical nondimensionalization & Express MHD using reference scales. & Determines the dimensionless equations and interpretation of $\eta,\nu,t$. \\
Neural preprocessing & Improve numerical conditioning of inputs and targets. & Changes numbers presented to the network but is invertible and fitted only from training data. \\
\bottomrule
\end{longtable}

\subsection{Field standardization}
The primary view uses one training-only transform for each physical channel,
\[
\widetilde\psi=\frac{\psi-m_\psi}{s_\psi},\qquad
\widetilde U=\frac{U-m_U}{s_U},
\]
with $s_\psi,s_U>0$. The same $\psi$ transform applies to $\psi_0$ and target $\psi_t$; likewise for $U$.

\subsection{How field statistics are weighted}
If statistics were computed by naively concatenating every scalar grid value from every saved time, cases with more target times could dominate. Module~3 therefore freezes a weighting policy. The primary policy is case-balanced first, target-time balanced second, and area balanced third.

\subsection{Transport coefficients}
For positive coefficients spanning orders of magnitude, define
\[
r_\eta=\log_{10}\eta,\qquad r_\nu=\log_{10}\nu
\]
before affine scaling. If the range is narrow, direct affine scaling may be adequate. The transform is selected from training-design considerations and frozen before final testing.

\subsection{Target time}
For training interval $t\in[t_{\min},t_{\max}]$, a simple affine scale is
\[
\widetilde t=2\frac{t-t_{\min}}{t_{\max}-t_{\min}}-1.
\]
Testing at $t>t_{\max}$ produces $\widetilde t>1$ and is genuine scalar extrapolation.

\subsection{Leakage-free fitting}
Every learned transform must be fitted from training cases only:
\[
\mathcal{T}=\operatorname{fitTransform}(\mathcal{D}_{\rm train}).
\]
The same stored transform is then applied unchanged to validation and test cases.

\subsection{Gauge and mean conventions}
The dataset fixes the spatial mean of $U$ to zero. Arbitrary constant offsets in $U$ would add nonphysical variation to the regression target. The mean convention must be common across all cases before training. The same principle applies to the recorded mean of $\psi$.

\section{Partitioning and leakage control}
\label{sec:splits}

\subsection{Training, validation, and test roles}
The training set updates network weights. The validation set selects architecture, mode count, width, learning rate, training duration, and checkpoints. The test set is untouched until the design is frozen.

\subsection{The split unit is the complete physical case}
Let $\mathcal{C}_{\rm tr}$, $\mathcal{C}_{\rm va}$, and $\mathcal{C}_{\rm te}$ contain physical-case identifiers. They must be disjoint. Every target-time pair derived from one physical trajectory inherits its case partition.

\begin{warningbox}[\,: time-snapshot leakage]
Putting early times from one trajectory in training and later times from the same trajectory in test does not measure unseen-case generalization. The model has already seen the exact initial state and physical parameters of that trajectory.
\end{warningbox}

\subsection{Split before transforms and pair sampling}
The correct order is:
\begin{enumerate}
  \item validate accepted physical cases;
  \item freeze whole-case train/validation/test assignments;
  \item fit preprocessing from training cases only;
  \item choose target-time pair rules within each partition; and
  \item train and tune without test inspection.
\end{enumerate}

\subsection{Parameter interpolation versus extrapolation}
In the $(\eta,\nu)$ plane, an unseen test point inside a declared support such as the convex hull of training coefficients may be labeled interpolation. A point outside requires extrapolation. The current $A_0$ family is encoded through $U_0$ and should be analyzed separately as initial-state amplitude generalization.

\subsection{Initial-state generalization in version 1}
Because
\[
\psi_0=\sin x\sin y,\qquad U_0=A_0(\cos x-\cos y),
\]
all initial states lie on a very low-dimensional family. Holding out $A_0=0.10$ while training on $A_0=0.05$ and $0.20$ tests amplitude interpolation of one fixed shape. It does not test a new magnetic topology or new flow morphology.

\section{The strict data-only objective}
\label{sec:loss}

\subsection{Full-field pointwise errors}
For example $(c,n)$ and grid index $(i,j)$, define standardized errors
\[
e_{\psi,c,n,i,j}=\widehat{\widetilde\psi}_{c,n,i,j}-\widetilde\psi_{c,n,i,j},
\]
\[
e_{U,c,n,i,j}=\widehat{\widetilde U}_{c,n,i,j}-\widetilde U_{c,n,i,j}.
\]
The per-field area-mean squared errors are
\[
E_{\psi,c,n}=\frac{1}{N_xN_y}\sum_{i,j}e_{\psi,c,n,i,j}^2,
\qquad
E_{U,c,n}=\frac{1}{N_xN_y}\sum_{i,j}e_{U,c,n,i,j}^2.
\]

\subsection{Channel-balanced operator loss}
After separate output standardization, the primary example loss is
\[
\ell_{c,n}=\lambda_\psi E_{\psi,c,n}+\lambda_U E_{U,c,n},
\qquad \lambda_\psi=\lambda_U=1.
\]

\subsection{Case-balanced empirical risk}
If each case contributes a different number of selected target times, a global pair average weights dense cases more heavily. The primary training risk first averages over target times within each selected case and then over cases:
\begin{equation}
\Ldata=
\frac{1}{|\mathcal B_C|}
\sum_{c\in\mathcal B_C}
\frac{1}{|\mathcal B_t(c)|}
\sum_{n\in\mathcal B_t(c)}\ell_{c,n}.
\label{eq:case_balanced_loss}
\end{equation}

\subsection{The strict Module 4 loss}
\begin{conventionbox}[\,: value-only full-field baseline]
The primary Module~4 objective is
\[
\boxed{\Ltrain=\Ldata.}
\]
No target $J$, target $\omega$, PDE residual, gradient target, spectral-coefficient target, initial-condition penalty, boundary penalty, gauge penalty, or global-balance penalty may update the weights.
\end{conventionbox}

\subsection{Are spectral losses still data-only?}
A loss comparing predicted and target Fourier coefficients contains no PDE and is data-supervised in a broad sense. However, it supplies frequency-weighted information beyond the strict pointwise field loss. The same is true for gradient losses, current losses, or vorticity losses. These are useful enhanced-data baselines but must not silently replace the primary value-only experiment.

\subsection{Why squared error is reasonable and limited}
MSE is differentiable and strongly penalizes large errors, but area-averaging can underweight a thin current sheet because the sheet occupies little area. That limitation is handled in evaluation and controlled loss ablations rather than by changing the primary objective after seeing test results.

\subsection{Weight decay and numerical regularization}
Weight decay, optimizer momentum, learning-rate schedules, and gradient clipping are numerical/statistical training choices, not MHD physics. They may be used if declared and matched appropriately in Module~5.

\section{Training the operator}
\label{sec:training}

\subsection{What training changes}
The operator contains trainable real and complex-valued parameters, represented internally by real tensors. The loss is a scalar function $\Ltrain(\theta)$. Backpropagation computes
\[
\nabla_\theta\Ltrain.
\]
An optimizer uses this gradient to update the parameters.

\subsection{Backpropagation through FFT operations}
The discrete FFT, complex multiplication, inverse FFT, pointwise affine maps, and activations are differentiable operations in modern frameworks. Backpropagation therefore propagates field-loss sensitivities through every FNO layer into its spectral and local weights.

This training derivative is with respect to network parameters. It should not be confused with physical derivatives such as $\partial_x\psi$ or $\partial_t\psi$.

\subsection{Mini-batches}
A batch contains complete full-field examples, not isolated pixels. For $B$ examples on a $128\times128$ grid with several latent channels, activation memory can be substantial. Batch size is therefore constrained by accelerator memory and must be recorded.

\subsection{Hierarchical batch sampling}
A defensible sampler:
\begin{enumerate}
  \item selects physical cases approximately uniformly;
  \item selects one or more target times within each chosen case; and
  \item loads the complete field pair for each selected $(c,n)$.
\end{enumerate}
This controls correlation better than sampling uniformly from a flat list dominated by trajectories with many saved times.

\subsection{Adam and learning-rate schedule}
Adam \cite{Kingma2015} is a practical starting optimizer. A typical staged schedule begins with a moderate learning rate, reduces it when validation error plateaus or by a predeclared cosine schedule, and saves the checkpoint with the best declared validation metric. The exact schedule is a hyperparameter, not a physical law.

\subsection{Epoch, update, and examples processed}
An optimizer update changes the network once. An epoch approximately processes one pass through a declared finite pair set. If target times are resampled each epoch, the meaning of epoch becomes approximate. The project therefore logs updates, examples processed, and wall-clock time in addition to epochs.

\subsection{Repeated random seeds}
Initialization, batch order, and accelerator kernels can cause run-to-run variation. Final comparisons should train several seeds and report mean, spread, and failures rather than only the best run.

\subsection{Staged implementation strategy}
Before full training:
\begin{enumerate}
  \item verify exact HDF5-to-tensor round trip;
  \item verify $t=0$ identity examples;
  \item overfit one target pair;
  \item overfit one complete trajectory with several target times;
  \item train a small multi-case model;
  \item inspect validation fields and spectra;
  \item freeze the primary configuration; and
  \item train repeated seeds for the untouched test evaluation.
\end{enumerate}
Overfitting a tiny dataset is a debugging test, not evidence of generalization.

\section{Hyperparameters and controlled architecture selection}
\label{sec:hyperparameters}

\subsection{Trainable parameters versus hyperparameters}
Trainable parameters are updated by gradient descent. Hyperparameters include latent width, number of spectral layers, retained mode counts, activation, optimizer, learning rate, batch size, weight decay, target-time sampling, and early-stopping patience.

\subsection{Mode count is physically consequential}
Current density contains two spatial derivatives. For a Fourier mode of wave number $k$, the current contribution scales as $k^2\psi_k$. Consequently, a network that predicts low modes accurately while smoothing high modes can achieve good $\psi$ MSE but poor $J$. Mode-count selection must therefore inspect derivative-sensitive validation diagnostics, not only field MSE.

\subsection{Width and depth}
Greater width increases the number of latent channels available at each wave number. Greater depth composes more nonlinear global-local transformations. Both increase capacity and compute. A larger model is not automatically more physical or more data-efficient.

\subsection{Validation metric selection}
A predeclared primary validation score may combine relative $L_2$ field errors for $\psi$ and $U$. Secondary validation diagnostics can include $J$, $\omega$, energy, and peak-current errors. If secondary diagnostics choose the checkpoint or architecture, that influence must be disclosed and applied consistently to Module~5.

\subsection{Search budget fairness}
One method should not receive vastly more architecture trials or manual tuning than the other. The project records the search space, number of trials, compute budget, selection rule, and final frozen configuration for both Modules 4 and 5.

\section{Complete-field inference}
\label{sec:inference}

\subsection{One operator query}
Given a new accepted-style initial state and context:
\begin{enumerate}
  \item validate grid, channels, and metadata;
  \item apply stored training-only transforms;
  \item broadcast transformed $\eta$, $\nu$, and $t$;
  \item evaluate the FNO once on the complete field;
  \item inverse-transform the two output channels; and
  \item return $(\widehat\psi_t,\widehat U_t)$ with model and preprocessing provenance.
\end{enumerate}

\subsection{A trajectory}
To reconstruct a trajectory at times $t_1,\ldots,t_m$, evaluate the time-conditioned operator for each requested $t_k$. These queries can be batched because they share the same initial fields but differ in the time channel.

\subsection{Inference cost must match the scientific task}
The relevant comparison is full-field prediction time, not the cost of one pixel or one Fourier coefficient. Report end-to-end latency including tensor transforms and device transfer when comparing with the reference solver.

\subsection{No recursive error accumulation, but possible temporal inconsistency}
Direct time conditioning avoids recursive propagation of the model's own previous output. However, predictions at $t_1$ and $t_2$ are produced independently and need not form a dynamically consistent trajectory. Module~5 physics terms and evaluation-only temporal diagnostics can expose such inconsistency.

\section{Evaluation on complete unseen fields}
\label{sec:evaluation}

\subsection{Why training loss is not the scientific result}
Training loss measures fit in transformed coordinates on observed pairs. Scientific evaluation uses inverse-transformed dimensionless fields from whole held-out cases and target times.

\subsection{Absolute and relative field errors}
For $a\in\{\psi,U\}$,
\[
e_a(x_i,y_j)=\widehat a_{ij}-a_{ij}.
\]
A discrete relative $L_2$ error is
\[
\RelLtwo(a)=
\frac{\left(\sum_{i,j}|\widehat a_{ij}-a_{ij}|^2\right)^{1/2}}
{\max\!\left[\left(\sum_{i,j}|a_{ij}|^2\right)^{1/2},\epsilon\right]}.
\]
Also report absolute RMSE and relative maximum error.

\subsection{Per-case and aggregate reporting}
Report each held-out physical case separately before aggregate statistics. A mean over all target-time pairs can hide one failed parameter regime. Recommended summaries include median, mean, worst case, and distribution across random seeds.

\subsection{Time-resolved error}
For a held-out trajectory, plot or tabulate field error versus target time. Reconnection is a transient event; an average across time can hide a severe error near current-sheet formation.

\subsection{Spectral error}
On the common periodic grid, compare Fourier spectra of predicted and reference fields. Define shell or mode-wise energy errors and inspect whether the operator loses high-wavenumber content as the current sheet sharpens.

\subsection{Amplitude error versus phase/topology error}
A prediction can have similar energy but place an island or X-point at the wrong location. Contours remain useful visualization tools for evaluation, but metrics must quantify topology and critical-point location rather than relying on visual similarity alone.

\section{Physical diagnostics that remain evaluation-only}
\label{sec:diagnostics}

\subsection{Derived current and vorticity}
For predicted complete fields, use the same declared spectral derivative convention as the reference grid:
\[
\widehat J=-\Lap\widehat\psi,\qquad
\widehat\omega=\Lap\widehat U.
\]
This is preferable to image processing or arbitrary finite differences because it matches the periodic numerical representation.

\subsection{Magnetic and kinetic energy}
Evaluate
\[
\widehat E_B=\frac12\int_\Omega|\nabla\widehat\psi|^2\,\dd A,
\qquad
\widehat E_K=\frac12\int_\Omega|\nabla\widehat U|^2\,\dd A.
\]
Compare both instantaneous values and histories with the reference trajectory.

\subsection{Peak current and current-sheet structure}
Record
\[
\widehat J_{\max}(t)=\|\widehat J\|_\infty,
\]
its location, sheet width, and if available the same orientation/width diagnostic used by Module~2. Thin sheets are precisely where field MSE can be misleading.

\subsection{O-points, X-points, and reconnected flux}
Apply the Module~2 critical-point and reconnection definitions to the predicted $\widehat\psi$. Compare O/X locations, O-to-X flux contrast, reconnected flux, and event timing. These diagnostics test whether the surrogate reproduces magnetic topology rather than only array averages.

\subsection{Periodicity}
An FNO on a periodic FFT grid naturally uses wrap-around Fourier representation, but implementation mistakes can still enter through preprocessing or tensor conversion. Evaluate periodic seam and derivative consistency explicitly when reconstructing continuous diagnostics.

\subsection{Evaluation-only reduced-MHD residuals}
The predicted fields can be inserted into
\[
\Rpsi=\psi_t+\bracket{U}{\psi}-\eta\Lap\psi,
\]
\[
\Romega=\omega_t+\bracket{U}{\omega}-\bracket{J}{\psi}-\nu\Lap\omega.
\]
For a time-conditioned operator, spatial derivatives can be computed spectrally and $\partial_t$ may be obtained by automatic differentiation with respect to the scalar time channel if the implementation preserves that graph, or by a carefully defined temporal diagnostic. These residuals remain evaluation-only in Module~4.

\begin{warningbox}[\,: diagnostic use versus training use]
Computing a PDE residual after training does not turn the model into a PINN. Using that residual to update weights does. If residual-based model selection is used, it influences the experimental design and must be disclosed even though it is not a gradient term.
\end{warningbox}

\subsection{Energy-balance defect}
For the predicted trajectory evaluate the reduced-MHD dissipation identity
\[
\frac{\dd E}{\dd t}
=-\eta\int J^2\,\dd A-\nu\int\omega^2\,\dd A
\]
as an evaluation diagnostic. A data-only operator is not required to satisfy it exactly.

\section{Generalization experiments}
\label{sec:generalization}

\subsection{Transport-parameter interpolation}
Hold out entire $(\eta,\nu)$ cases inside the training support. The initial field may still resemble training states, but the model must infer dynamics at a new transport combination.

\subsection{Transport-parameter extrapolation}
Evaluate coefficients outside the training support. This is more difficult because the operator must extrapolate the effect of diffusion rather than interpolate it.

\subsection{Time interpolation}
If target times inside $[0,T]$ are sparsely labeled for training, evaluate unlabeled intermediate times from held-out cases. This tests continuous time conditioning within the represented interval.

\subsection{Time extrapolation}
Train only through $T_{\rm train}$ and evaluate at $t>T_{\rm train}$. This is a separate experiment. A continuous time input does not imply reliable forecasting.

\subsection{Initial-amplitude interpolation}
Under the current family, holding out one $A_0$ tests whether the operator can infer an intermediate complete $U_0$ amplitude. The operator receives the field itself, not the label $A_0$.

\subsection{Initial-shape generalization}
A future stronger experiment should generate additional verified $\psi_0$ and/or $U_0$ shapes. Only then can the project test whether the learned operator generalizes between distinct initial spatial structures. This extension belongs first in Module~2 case generation and Module~3 schema/view design.

\subsection{Resolution transfer}
An FNO can in principle be evaluated on a different discretization when the spectral implementation and learned modes are compatible. Nevertheless, the current baseline should first test same-grid accuracy. A resolution-transfer experiment must use an independent higher-resolution reference and report whether thin current sheets remain resolved.

\section{Data efficiency and learning curves}
\label{sec:dataeff}

\subsection{Several distinct data budgets}
For a full-field operator, ``number of training points'' is no longer the most meaningful budget. Report separately:
\begin{itemize}
  \item number of independent physical trajectories;
  \item number of selected target times per trajectory;
  \item spatial resolution of each field;
  \item number of observed output channels; and
  \item total reference-solver cost required to generate the labeled fields.
\end{itemize}

\subsection{Trajectory scarcity versus snapshot scarcity}
Reducing target times from 100 to 20 within the same 27 trajectories is different from reducing the number of trajectories from 27 to 6. The first removes temporal labels but keeps physical-case diversity. The second removes independent variation in initial conditions and transport parameters.

\subsection{Learning curves}
A useful study varies both axes:
\[
N_{\rm case}\in\{\text{small, medium, full}\},
\qquad
N_{t,\rm label}\in\{\text{sparse, medium, dense}\}.
\]
Module~4 and Module~5 should use identical labeled pairs at each budget.

\subsection{Reference cost matters}
One full-field target may contain many scalar values, but its expensive information source is the reference simulation. Data-efficiency claims should therefore report solver runs and saved fields, not merely scalar tensor elements.

\section{Failure modes and their signatures}
\label{sec:failures}

\subsection{Underfitting}
Training and validation errors both remain high; broad topology may be reproduced while small structures are absent. Increase capacity or improve optimization only after confirming data and transforms.

\subsection{Overfitting}
Training error falls while unseen-case error worsens. Large spectral models can memorize a small set of trajectories despite many apparent target-time pairs.

\subsection{Trajectory memorization}
If case diversity is small, the network may interpolate labels associated with familiar initial fields rather than learn a robust solution operator. Dense temporal sampling cannot replace independent initial-state diversity.

\subsection{High-frequency smoothing}
Predicted $\psi$ contours look good but $J$ is too small or too broad. The spectral tail of $\widehat\psi$ decays too rapidly compared with the reference. Increase validated mode capacity or reconsider the architecture; do not infer accuracy from contours alone.

\subsection{Spectral ringing}
Sharp structures can produce oscillatory errors around a current sheet. Inspect physical-space error and spectra. More modes are not always the solution if the reference itself is near its resolution limit.

\subsection{Scalar-conditioning failure}
The network reproduces average behavior but responds weakly to changes in $\eta$ or $\nu$. Compare cases with identical or similar initial fields across transport coefficients and inspect sensitivity of outputs to context channels.

\subsection{Temporal inconsistency}
Predictions at neighboring target times are individually plausible but jump nonphysically because each query is independent. Time-resolved diagnostics and evaluation-only PDE/energy defects reveal the problem.

\subsection{Gauge contamination}
An arbitrary spatially constant offset appears in $U$. This can give small velocity error but large direct $U$ loss. Enforce the dataset gauge consistently rather than post-hoc shifting test predictions without declaring the procedure.

\subsection{Grid transposition}
Square fields can be accidentally transposed and still look plausible. Module~3 requires explicit axis metadata and non-square sentinel tests for packing parity.

\subsection{Rendered-image contamination}
If a contour image or color map enters the learning pipeline, numerical meaning depends on plotting choices and precision is lost. The remedy is to return to raw HDF5 field arrays.

\subsection{Test leakage}
Using test spectra to select mode count, test field means to normalize outputs, or target times from the same physical trajectory across partitions produces optimistic results.

\subsection{False M3D-C1 interpretation}
A network can be excellent on the synthetic periodic two-field system and still have no demonstrated accuracy on M3D-C1. Architecture similarity does not close the model-discrepancy gap.

\section{Fair comparison with the Module 5 physics-informed operator}
\label{sec:fairness}

\subsection{What should be held fixed}
The primary comparison should hold fixed:
\begin{itemize}
  \item physical-case train/validation/test split;
  \item labeled operator pairs;
  \item input/target channel semantics;
  \item grid and tensor packing;
  \item preprocessing transforms;
  \item FNO architecture, width, layers, modes, activation, and projection unless a controlled reason requires otherwise;
  \item data-loss definition;
  \item random seeds where meaningful; and
  \item scientific evaluation metrics.
\end{itemize}
Module~5 additionally receives physics collocation/evaluation information and physics-loss terms.

\subsection{Three notions of fairness}
\textbf{Label fairness} means the same reference field labels. \textbf{Architecture fairness} means comparable representational capacity. \textbf{Compute fairness} means runtime and memory differences are reported rather than hidden. Physics-informed training may use much more compute while using the same labels.

\subsection{Matched labeled-data budgets}
For each budget, the immutable set of labeled $(c,n)$ pairs is identical in Modules 4 and 5. Additional Module~5 collocation times or physics evaluations do not count as new labels but must be counted in compute.

\subsection{Ablation ladder}
A useful sequence is:
\begin{enumerate}
  \item data-only FNO;
  \item data-only FNO plus optional enhanced data loss, if studied separately;
  \item data + magnetic-flux PDE physics;
  \item data + both PDEs;
  \item data + PDEs + initial/gauge constraints where needed;
  \item optional global balances.
\end{enumerate}
This identifies which information channel produces any observed benefit.

\subsection{What counts as evidence that physics helped?}
Examples include lower unseen-case field and derivative error at the same labels, better current-sheet and reconnection fidelity, lower data requirement for a fixed accuracy target, or improved extrapolation without unacceptable compute or failure-rate cost. Lower training residual by itself is not sufficient.

\section{Recommended version-1 baseline specification}
\label{sec:spec}

\begin{conventionbox}[\,: primary data-only full-field operator]
\begin{itemize}
  \item Task: $(\psi_0,U_0,\eta,\nu,t)\mapsto(\widehat\psi_t,\widehat U_t)$.
  \item Data: accepted Module~3 full-field numerical arrays only; no rendered images.
  \item Split: whole physical cases before transforms and target-time pair extraction.
  \item Grid: one common accepted periodic production grid per physical case.
  \item Input channels: standardized $\psi_0,U_0$ plus broadcast transformed $\eta,\nu,t$; no duplicate $A_0$ channel.
  \item Target channels: standardized $\psi_t,U_t$.
  \item Architecture: 2D FNO, width 32, four spectral blocks, starting retained modes $16\times16$, no nonperiodic padding, smooth frozen activation.
  \item Loss: case-balanced, target-time-balanced, channel-balanced full-field value MSE only.
  \item Optimizer: Adam with a predeclared learning-rate schedule.
  \item Model selection: validation cases only.
  \item Final reporting: repeated seeds and complete-field physical diagnostics on untouched test cases.
\end{itemize}
\end{conventionbox}

\subsection{Why this is only a starting point}
The architecture is chosen for transparency and compatibility with the periodic structured grid. A competent validation study can change width, modes, activation, or number of layers before final testing. The frozen primary comparison must then use the selected configuration consistently in Module~5.

\subsection{Suggested controlled ablations}
Useful ablations include:
\begin{itemize}
  \item $8$, $16$, and $24$ retained modes;
  \item width $16$, $32$, and $64$;
  \item scalar broadcast versus learned scalar embedding;
  \item direct time-conditioned operator versus autoregressive time-stepper;
  \item value-only versus value-plus-spectral data loss;
  \item with and without deterministic coordinate channels; and
  \item FNO versus a conventional U-Net of comparable capacity.
\end{itemize}
Each ablation answers a different architectural question and should not be mixed into the physics-informed comparison without labeling it.

\section{Worked miniature examples}
\label{sec:examples}

\subsection{Example 1: pure resistive decay}
With $U_0=0$ and the initial magnetic eigenmode from Module~2,
\[
\psi(x,y,t)=e^{-2\eta t}\sin x\sin y,\qquad U=0.
\]
For this restricted family the exact solution operator is
\[
(\sin x\sin y,0,\eta,\nu,t)
\mapsto
(e^{-2\eta t}\sin x\sin y,0).
\]
A network can learn the scalar decay law while preserving the spatial mode. This is a useful debugging problem because truth is analytic.

\subsection{Example 2: why full-field input contains $A_0$}
Consider two initial flow amplitudes,
\[
U_0^{(1)}=0.05(\cos x-\cos y),\qquad
U_0^{(2)}=0.20(\cos x-\cos y).
\]
The input arrays differ point by point. The network does not need a separate label to know which amplitude it received. Nevertheless, both fields share exactly the same normalized shape, so this experiment does not represent arbitrary initial-flow learning.

\subsection{Example 3: field MSE can hide current error}
Let a predicted magnetic flux contain a small high-frequency error,
\[
\widehat\psi=\psi+\epsilon\sin(kx)\sin(ky).
\]
The flux error amplitude is $O(\epsilon)$, but
\[
\widehat J-J
=-\Lap(\widehat\psi-\psi)
=2k^2\epsilon\sin(kx)\sin(ky),
\]
so current error grows like $k^2$. This is why retained FNO modes and derivative diagnostics matter.

\subsection{Example 4: pair count is not case count}
Suppose 9 training trajectories each contribute 80 target times. The training loader sees 720 operator pairs, but the model has only 9 independent initial-value problems. A validation set containing another time from those same 9 trajectories would not test new-case generalization.

\section{Reproducibility and implementation handoff}
\label{sec:repro}

\subsection{Configuration that must be saved}
Each run records at least:
\begin{itemize}
  \item dataset release and operator-view identifiers;
  \item immutable split manifest digest;
  \item selected target-time rule and labeled pair IDs;
  \item grid signature and channel order;
  \item field and scalar preprocessing parameters;
  \item FNO width, layer count, retained mode counts, activation, and padding rule;
  \item exact parameter count;
  \item optimizer, learning-rate schedule, weight decay, batch size, and gradient clipping;
  \item random seed and framework/device information;
  \item checkpoint selection metric and patience;
  \item training updates, examples processed, wall-clock time, and peak memory; and
  \item source revision/configuration digest.
\end{itemize}

\subsection{Acceptance tests before full training}
Mandatory tests include:
\begin{enumerate}
  \item exact HDF5-to-tensor channel and axis round trip;
  \item non-square sentinel grid packing test;
  \item $t=0$ identity target construction;
  \item inverse preprocessing round trip;
  \item one-batch forward shape and finite-value check;
  \item one-batch backward finite-gradient check;
  \item overfit-one-pair test;
  \item overfit-one-trajectory test;
  \item periodic FFT ordering test for predicted diagnostic derivatives; and
  \item deterministic evaluation-mode repeatability.
\end{enumerate}

\subsection{Minimum run products}
Save the best checkpoint, final configuration, training/validation histories, seed information, test predictions or reproducible prediction indices, per-case metrics, time-resolved metrics, field/spectral error products, $J/\omega$ diagnostics, topology/reconnection metrics, runtime data, and a machine-readable summary.

\subsection{Runtime quantities}
Report training wall time, accelerator type, peak memory, full-field inference latency, throughput for batched target times, parameter count, and reference-solver cost. A model that saves labels but requires dramatically more training compute may still be useful, but the tradeoff must be visible.

\section{Common misconceptions}
\label{sec:misconceptions}

\subsection{``A neural operator takes images''}
It takes numerical fields. A 2D tensor is not automatically an image; each entry has a physical scalar meaning tied to coordinates, normalization, and provenance.

\subsection{``More target times mean more independent simulations''}
They produce more supervised pairs, not more independent trajectories.

\subsection{``The full initial field means arbitrary initial-condition generalization''}
Not in version~1. The initial fields still come from a narrow analytic family.

\subsection{``$A_0$ disappeared from the physics''}
No. It still defines the version-1 initial flow and is stored as metadata. It is simply encoded directly in $U_0$ and therefore need not be duplicated as a neural input channel.

\subsection{``An FNO is physics-informed because it uses Fourier modes''}
No. Fourier transformation is an architectural/numerical representation. The model becomes physics-informed only when declared physical information affects training.

\subsection{``Low field MSE guarantees good reconnection physics''}
No. Current sheets, derivatives, X-points, and event timing can be wrong despite visually good fields.

\subsection{``A time-conditioned operator forecasts automatically''}
No. Evaluation within the training time interval is interpolation. Forecasting requires explicit time extrapolation.

\subsection{``More Fourier modes always improve the model''}
No. More modes increase capacity and cost and may fit numerical noise. Validation must determine whether they improve resolved physical diagnostics.

\subsection{``FNO resolution independence means exact super-resolution''}
No. An architecture may accept another grid, but accuracy depends on training support and physical resolution.

\subsection{``Broadcasting $\eta$ means resistivity varies in space''}
No. The broadcast channel is constant over the field for one case. It is only an input representation.

\subsection{``A good synthetic operator is already an M3D-C1 surrogate''}
No. Genuine M3D-C1 field mappings, geometry, closures, meshes, and validation are still required.

\section{Module 4 computational contract}
\label{sec:contract}

\subsection{Input-output contract}
For one operator example,
\[
(\psi_0[N_x,N_y],U_0[N_x,N_y],\eta,\nu,t)
\longmapsto
(\widehat\psi_t[N_x,N_y],\widehat U_t[N_x,N_y]).
\]
The fields are raw numerical scalar arrays on the common periodic grid. $A_0$ remains metadata and is already encoded in $U_0$ for version~1.

\subsection{Data contract}
Only accepted Module~3 cases may enter. Whole physical cases are split before pair extraction and preprocessing. Training transforms are fitted from training cases only. No rendered image enters the learning path.

\subsection{Architecture contract}
The primary model is a 2D FNO with explicit lifting, four global-local spectral blocks, and two-channel projection. Exact width, modes, activation, and optimizer choices are frozen after validation and logged.

\subsection{Loss contract}
\[
\Ltrain=\Ldata
\]
with case-balanced, target-time-balanced, channel-balanced full-field value MSE. Any derivative, Fourier-target, PDE, boundary, gauge, or balance term defines a different experiment.

\subsection{Evaluation contract}
Evaluate inverse-transformed complete fields on untouched cases. Report $\psi,U,J,\omega$, spectra, energies, current-sheet measures, topology/reconnection diagnostics, evaluation-only residuals, and runtime.

\subsection{Fairness contract for Module 5}
Module~5 inherits the same operator task, split, labeled pairs, preprocessing, primary architecture, and data loss. Added physics information, collocation strategy, loss weighting, and added compute are separately recorded.

\section{Summary and bridge to Module 5}
\label{sec:summary}

Module~4 now learns the data-only full-field solution operator
\[
(\psi_0,U_0,\eta,\nu,t)\mapsto(\widehat\psi_t,\widehat U_t).
\]
The input and output are complete numerical scalar fields, not images. The version-1 initial perturbation amplitude $A_0$ remains physical metadata but is already encoded by $U_0=A_0(\cos x-\cos y)$, so it is not duplicated as a primary input channel.

The primary architecture is a two-dimensional Fourier neural operator on the common periodic grid. A lifting layer maps the two initial fields and three broadcast scalar-context channels into a latent representation. Repeated FNO blocks combine learned low-mode spectral convolution with local pointwise channel mixing and nonlinear activation. A projection layer returns $\psi$ and $U$.

The strict baseline is supervised only. Whole physical trajectories are partitioned before target-time extraction. Preprocessing is fitted from training cases only. The training objective contains only complete-field value error, averaged so that output channels, target times, and physical cases receive controlled weight.

Scientific evaluation goes well beyond tensor MSE. Current and vorticity, spectra, energies, current-sheet structure, critical points, reconnected flux, event timing, periodicity, and reduced-MHD residuals are evaluated after training. These diagnostics can reveal derivative or topology failure hidden by smooth contour plots.

The full-field representation creates a more natural bridge to future simulation exports, but the current initial-condition family remains narrow and all data remain synthetic reduced-MHD trajectories. No M3D-C1 surrogate claim follows yet.

Module~5 keeps this exact operator task and labeled-data baseline, then asks the controlled question: does adding the reduced-MHD equations and related physical constraints improve accuracy, data efficiency, extrapolation, or physical consistency enough to justify the added training complexity?

\section{Tensor and linear-algebra foundations}
\label{app:tensors}

\subsection{Scalar, vector, matrix, and tensor}
A scalar is one number. A vector is an ordered list of numbers. A matrix is a two-index array. A tensor is a multidimensional array. In this module, ``tensor'' primarily means the computational array used by a machine-learning framework; it need not imply a tensor transformation law from differential geometry.

A single target field has shape $N_x\times N_y$. Two output channels have shape $N_x\times N_y\times2$. A batch adds another axis.

\subsection{Channel mixing as matrix multiplication}
At one grid point, the lifting layer maps five channels to $d$ channels:
\[
\vect v=P\vect a+\vect b.
\]
The same $P$ is applied independently at every spatial point. This is equivalent to a $1\times1$ convolution in image-processing terminology, but here the channels are physical/latent fields rather than colors.

\subsection{Complex spectral weights}
A complex number is $z=a+ib$. Multiplying a Fourier coefficient by a complex weight can change both amplitude and phase. Machine-learning frameworks store these weights directly as complex tensors or as paired real and imaginary parts.

\section{Discrete Fourier representation used by the FNO}
\label{app:fourier}

\subsection{Periodic Fourier modes}
For $L_x=L_y=2\pi$,
\[
f(x,y)=\sum_{m,n}\widehat f_{mn}e^{i(mx+ny)}.
\]
The discrete FFT maps sampled field values to discrete coefficients. The inverse FFT reconstructs the grid field under the library's normalization convention.

\subsection{Why spectral convolution is global}
A Fourier coefficient
\[
\widehat f_{mn}=\sum_{j,\ell}f_{j\ell}e^{-i(mx_j+ny_\ell)}
\]
depends on all grid points. Therefore modifying one retained Fourier mode changes the reconstructed field across the entire domain.

\subsection{Spectral mode truncation versus solver dealiasing}
The FNO's learned-mode truncation and the reference solver's two-thirds dealiasing serve different purposes. Solver dealiasing prevents nonlinear numerical products from folding unresolved modes into resolved modes. FNO mode truncation limits the learned spectral kernel for architectural efficiency. They must not be conflated.

\subsection{Derivative amplification}
For a mode $e^{i(k_xx+k_yy)}$,
\[
\Lap e^{i(k_xx+k_yy)}=-(k_x^2+k_y^2)e^{i(k_xx+k_yy)}.
\]
Thus high-wave-number flux error is strongly amplified in current. This mathematical fact motivates derivative-sensitive evaluation.

\section{Metric catalog}
\label{app:metrics}

\subsection{Mean absolute error}
For $N=N_xN_y$ scalar values,
\[
\MAE=\frac1N\sum_{p=1}^{N}|\widehat a_p-a_p|.
\]

\subsection{Mean squared error and root mean squared error}
\[
\MSE=\frac1N\sum_{p=1}^{N}(\widehat a_p-a_p)^2,
\qquad
\RMSE=\sqrt{\MSE}.
\]

\subsection{Relative $L_2$ error}
\[
\RelLtwo(a)=\frac{\|\widehat a-a\|_2}{\max(\|a\|_2,\epsilon)}.
\]

\subsection{Relative maximum error}
\[
e_{\infty,\rm rel}(a)=
\frac{\|\widehat a-a\|_\infty}{\max(\|a\|_\infty,\epsilon)}.
\]

\subsection{Spectral relative error}
For Fourier coefficients,
\[
e_{\rm spec}(a)=
\frac{\|\widehat{\widehat a}-\widehat a_{\rm ref}\|_2}
{\max(\|\widehat a_{\rm ref}\|_2,\epsilon)},
\]
where the outer hat denotes Fourier transform only in this appendix; implementation notation should avoid ambiguity with neural prediction hats.

\subsection{Event-time error}
If $t_*^{\rm ref}$ is the time of a reference peak and $t_*^{\rm pred}$ the predicted peak,
\[
e_t=|t_*^{\rm pred}-t_*^{\rm ref}|.
\]
Peak amplitude and peak time should be reported separately.

\section{Concept questions and answer sketches}
\label{app:questions}

\subsection*{Questions}
\begin{enumerate}[label=\textbf{Q\arabic*.}]
  \item Why is a data-only baseline necessary before adding physics-informed losses?
  \item What is the exact version-1 Module~4 operator map?
  \item Why are the 2D field arrays not treated as ordinary images?
  \item Why does one physical trajectory create many operator pairs but only one independent case?
  \item Why must the train/validation/test split occur before target-time pair extraction?
  \item Why is $A_0$ not duplicated as a primary network input?
  \item Why must $A_0$ still remain metadata?
  \item What is the difference between a coordinate network and a neural operator?
  \item What is the difference between the time-conditioned operator and an autoregressive time-stepper?
  \item What does the FNO lifting layer do?
  \item What does a spectral convolution layer do?
  \item Why is the spectral convolution global in space?
  \item Why retain a local pointwise branch in an FNO block?
  \item Why can too few retained modes damage current prediction?
  \item Why is zero padding not part of the primary periodic-domain baseline?
  \item What do the broadcast $\eta$, $\nu$, and $t$ channels mean physically?
  \item Why does continuous time input not prove forecasting ability?
  \item What is the strict Module~4 training loss?
  \item Can a Fourier-target loss still be called data-only?
  \item Why is field MSE insufficient for magnetic reconnection assessment?
  \item How should $J$ and $\omega$ be derived from predicted fields?
  \item Can PDE residuals be evaluated without making Module~4 a PINN?
  \item What does holding out one $A_0$ value test in the current dataset?
  \item What additional dataset change is needed to test arbitrary initial-condition shapes?
  \item What should be held fixed in the Module~4 versus Module~5 comparison?
  \item What claim about M3D-C1 is justified by a successful Module~4 result?
\end{enumerate}

\subsection*{Answer sketches}
\begin{enumerate}[label=\textbf{A\arabic*.}]
  \item It measures what labeled field data alone can accomplish, so any change from added physics can be identified rather than assumed.
  \item $(\psi_0,U_0,\eta,\nu,t)\mapsto(\widehat\psi_t,\widehat U_t)$ on complete numerical fields.
  \item Each array entry is a quantitative scalar field value tied to physical coordinates and normalization; rendering introduces color maps, rasterization, and information loss.
  \item Target times share the same initial-value problem and are strongly correlated; pair count is not trajectory diversity.
  \item Otherwise different times from the same trajectory can leak across partitions and preprocessing can use held-out information.
  \item In version~1, $U_0=A_0(\cos x-\cos y)$ already contains the amplitude everywhere on the grid.
  \item It is part of the physical case definition and provides a consistency/provenance check even if it is not duplicated in the neural tensor.
  \item A coordinate network returns field values at queried coordinates; a neural operator maps an entire input field/function to an entire output field/function.
  \item The time-conditioned operator predicts a requested target time directly from the initial state; a time-stepper recursively advances previous states.
  \item It converts the physical input channels at each grid point into a wider latent feature vector.
  \item It FFTs latent fields, applies learned complex channel mixing to retained modes, and inverse transforms the result.
  \item Each Fourier coefficient depends on the whole spatial domain, so changing it affects the reconstructed field globally.
  \item It supplies local channel transformation and an information path not limited to the learned spectral band.
  \item Current involves a Laplacian, so high-wavenumber flux errors are amplified by $k^2$.
  \item The physical domain is already periodic; arbitrary zero padding changes the topology and is unnecessary for the primary representation.
  \item They are constant context values repeated spatially for architectural convenience; they are not spatially varying coefficients.
  \item The network can be evaluated at any numerical time, but accuracy outside the represented interval is extrapolation and must be tested.
  \item A case-balanced, time-balanced, channel-balanced complete-field value MSE and nothing else.
  \item Yes in a broad sense, because it uses target data rather than a PDE, but it is an enhanced-data baseline and should be labeled separately from the strict value-only baseline.
  \item Reconnection depends on derivatives, thin current sheets, topology, and event timing that can be wrong despite low area-averaged field error.
  \item Use the same periodic spectral derivative convention: $J=-\Lap\psi$ and $\omega=\Lap U$.
  \item Yes, if residuals are evaluation-only and never update the weights.
  \item It tests interpolation or extrapolation in the amplitude of one fixed analytic flow shape, not a new initial morphology.
  \item Module~2 must generate additional independently verified initial-field shapes and Module~3 must include them in the operator release/splits.
  \item The physical splits, labeled pairs, preprocessing, operator task, baseline architecture, data loss, seeds where meaningful, and scientific metrics.
  \item Only that a data-only full-field operator approximates the synthetic two-field reduced-MHD dataset over the tested domain. Genuine M3D-C1 fidelity remains untested.
\end{enumerate}
